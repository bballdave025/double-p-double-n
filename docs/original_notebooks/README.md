# Original Kindle Scribe notebooks

This directory holds the **unaltered PDF exports** of the four
handwritten notebooks for the [Paper–Pencil Neural Networks (PPNN)](../../README.md)
project. They are primary working records, **not** polished tutorials or
reconstructed SVG diagrams.

The author has explicitly approved publication of the original handwritten
notebooks, including mistakes, revisions, detours, and unfinished material.

## How to read these sources

The notebooks document the evolving physical and mathematical design of
PPNN: inputs, weight boxes, biases, neuron internals, network architectures,
hand calculations, and exercises. They include revisions and exploratory
notation that may differ from current canonical diagrams.

- **Read the handwritten page images**, not only extracted text. Kindle
  handwriting recognition can omit or distort diagrams, symbols, layout,
  and the relationships between calculations.
- Preserve the original page order and files. Any transcription,
  commentary, corrected figure, or polished tutorial belongs in a
  **separate** derivative document.
- Do not silently correct historical notation or interpret an old
  experimental diagram as a final design decision.
- When citing a notebook, specify **notebook part and PDF page**, and
  distinguish any handwritten cumulative page number from PDF pagination.
- The notes are a source record; the [context documents](../context_documents/)
  record the current project decisions and continuation status.

## Provenance and scope

These files are exports of handwritten Kindle Scribe notebooks. Earlier
photographs and physical diagrams may predate them; they are not necessarily
the earliest PPNN artifacts. Later laminated sheets, scanned photographs,
and reconstructed SVGs are separate source classes and should retain
their own provenance.
