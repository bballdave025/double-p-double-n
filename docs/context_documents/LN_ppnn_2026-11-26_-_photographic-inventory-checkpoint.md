# 5. Architecture decision: reusable internal 4-to-4 module

Earliest author-confirmed 4-to-4 draft:
`d2024-01-04_PPNN_4neuronsTo4Neurons_sketchy.pdf`.
Later monochrome 4-to-4 internal routing:
`img20250126_20360290.jpg`, 5100 x 6600, with 16 weight boxes.

The latter can eventually be adapted to original input nodes by
copying input shapes from existing diagrams, but not now. Use the
general 4-to-4 module and cross out or mask unused nodes and weights
instead of drawing every smaller variant. For training, unused
weights must remain masked/frozen; account for biases and outgoing
connections of unused neurons. Internal connection sheets represent
incoming neuron activations, not necessarily original input nodes.

# 6. Mathematical and visual continuity

Retain the approved empty input rounded rectangle, weight rectangle,
bias rectangle with line exiting top, oval neuron, prediction
parallelogram and target trapezoid. High-level diagrams may use
circles for neurons and omit explicit weight boxes. Day/night
strokes remain #232323 and #DCDCDC on transparent backgrounds.

Keep preactivation z distinct from activation a = g(z).
Use parenthesized layer subscripts, e.g. a_(L), leaving component
indices available for the eventual Einstein-style convention.
Residual is prediction minus target; per-example loss is script ell;
aggregate cost is J. The early handwritten loss expression resembling
sqrt(prediction^2 - target^2) is not generally real-valued and is
historical, not an approved objective. Correct it when selecting
the actual learning example, not during inventory.
